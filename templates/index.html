How The System Operates

Simple three-step workflow designed for dependable personal bookkeeping.

1

Record Incomes & Expenses

Log multi-source salary, freelancing, and investment credits alongside itemized daily expenses tagged across 9 standard categories.

2

Enforce Monthly Budgets

Assign explicit spending caps to discretionary areas like Dining, Entertainment, and Shopping. Receive automated visual threshold warnings.

3

Generate Gemini Insights

Trigger on-demand Gemini AI analysis to identify high-spending categories, examine savings ratios, and receive structured budget recommendations.

Technical Capabilities

Built on Python Flask, SQLite, and vanilla modern frontend standards.

Strict Data Isolation

All transactions and budgets are scoped strictly to the authenticated session ID via foreign-key constraints.

Indian Currency Formatting

Full INR (₹) representation adhering to the Indian numbering system across charts, tables, and AI prompts.

Chart.js Visualizations

Category spending distribution doughnut chart and a 6-month historical income vs expense trend bar graph.

Deterministic Fallback

If Gemini API is unreachable or rate limited, the built-in financial rule engine provides local calculations without crashing.
