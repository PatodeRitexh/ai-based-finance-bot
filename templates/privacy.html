Privacy Policy

Effective Date: January 1, 2026 | Self-Hosted Architecture

1. Architecture & Data Ownership

Personal Finance Advisor Bot is built as a self-hosted application. All financial records, income entries, expense itemizations, budget limits, and savings goals are stored locally in your SQLite instance database. The application does not transmit your personal financial ledger to external telemetry servers.

2. Information We Store

The application persists the following data points locally:

  • User account identity: Name, email address, and cryptographically salted password hashes.
  • Income records: Source name, numeric amount (INR), transaction date, and optional user notes.
  • Expense records: Category tags, numeric amount (INR), date, and optional item descriptions.
  • Budget planning: Category spending caps and monthly tracking periods.
  • Savings goals: Milestone titles, target amounts, current accumulated sums, and deadline dates.

3. Google Gemini AI Processing

When you explicitly choose to run the "AI Advisor" feature, the backend aggregates your current month's numerical figures (total income, total expense, category percentages, budget variances) and transmits them to the Google Gemini API using the API key configured in your local environment.

No bank account numbers, credentials, credit card numbers, or permanent identifiers are processed by or sent to the Gemini API. You control the API key and can revoke it at any time through Google AI Studio.

4. Passwords and Authentication

All passwords are salted and hashed using standard PBKDF2 / SHA-256 algorithms via Werkzeug security primitives. Plaintext passwords are never logged, stored, or exposed via API endpoints.

5. Data Retention and Deletion

Because the database is self-hosted on your machine or private server, you retain full rights over data lifecycle. Deleting an income, expense, budget, or goal immediately purges the record from the database. Removing the SQLite file permanently clears all records.

6. Disclaimer

AI-generated insights are provided solely for personal budgeting awareness. They do not constitute certified financial, tax, or investment advisory.
